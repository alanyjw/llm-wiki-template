# Notes on "Make It Stick"

A few ideas that landed while reading about how learning actually works:

- Re-reading feels productive but is one of the weakest study methods.
- Retrieval practice — testing yourself — is far more durable.
- Spacing practice over time beats massed practice ("cramming").
- Interleaving different topics improves transfer.

Want to apply this to how I pick up a new programming language.
